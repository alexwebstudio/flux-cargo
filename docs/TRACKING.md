# Трекинг грузов через Google-таблицу

Страница `/track`: клиент вводит трек-номер и 4 последние цифры телефона и видит
статус, этапы, историю и фотоотчёт. Данные берутся из Google-таблицы, сайт
перечитывает её раз в минуту. Пока таблица не подключена, работают демо-грузы.

## 1. Таблица

Создайте Google-таблицу, лист назовите **«Грузы»** и импортируйте шаблон
`docs/tracking-template.csv` (Файл → Импорт → Загрузить → «Заменить текущий лист»).

Один груз — одна строка. Порядок колонок любой, сайт находит их по названию в шапке.

| Колонка | Что писать |
|---|---|
| Трек-номер | `FC-250001`. Его вы сообщаете клиенту |
| Телефон | телефон клиента в любом формате; проверяются последние 4 цифры |
| Способ | `Авиа`, `Авто`, `Ж/Д` или `Море` |
| Откуда / Куда | города, например `Иу` и `Астана` |
| Груз, Вес, кг, Мест | описание, вес (`46,5`), количество мест |
| Ожидаем | ожидаемая дата прибытия `25.11.2026` |
| Менеджер | имя, которое увидит клиент |
| **Заявка … Выдан** | 8 колонок этапов: `Заявка`, `Выкуплен`, `Проверен`, `На складе`, `В пути`, `Таможня`, `Прибыл`, `Выдан`. **Когда этап пройден — поставьте дату** (`12.11.2026` или `12.11.2026 14:00`). Текущий статус = последний заполненный этап |
| Где сейчас | необязательно; показывается у последнего этапа (например, `Хоргос`) |
| Комментарий | необязательно; заметка к последнему этапу |
| Фото | необязательно; ссылки на фото через пробел или запятую |

Время в датах указывайте по Казахстану (UTC+5).

## 2. Подключение — вариант А (рекомендуется, таблица остаётся закрытой)

1. Google Cloud Console → создайте проект → включите **Google Sheets API**.
2. IAM → Сервисные аккаунты → создайте аккаунт → Ключи → JSON.
3. В таблице нажмите «Настройки доступа» и выдайте доступ «Читатель» на e-mail сервисного аккаунта.
4. Задайте переменные окружения (на хостинге, например Vercel → Settings → Environment Variables, или в `.env.local`):

```
GOOGLE_SHEET_ID=<id из адреса таблицы: /spreadsheets/d/ЭТОТ_ID/edit>
GOOGLE_SHEET_RANGE=Грузы
GOOGLE_SERVICE_ACCOUNT_EMAIL=<client_email из JSON>
GOOGLE_PRIVATE_KEY="<private_key из JSON, с \n внутри>"
```

## 3. Подключение — вариант Б (быстро, но таблица станет публичной по ссылке)

Файл → Поделиться → **Опубликовать в интернете** → лист «Грузы» → формат **CSV** → ссылку в

```
GOOGLE_SHEET_CSV_URL=https://docs.google.com/spreadsheets/d/e/.../pub?gid=0&single=true&output=csv
```

⚠️ Опубликованную таблицу может открыть любой, у кого есть ссылка, а в ней телефоны клиентов.
Подходит для теста, для работы лучше вариант А.

## Как это работает

- `lib/sheets.server.ts` читает таблицу (API или CSV), кэширует её на 60 секунд и превращает строку в груз.
- `lib/tracking.server.ts` берёт груз из таблицы, а если она не подключена — демо-грузы.
- `app/api/track/route.ts` отдаёт статус, только если совпали трек-номер и 4 цифры телефона.
  Телефон в браузер не уходит, частота запросов ограничена (10 в минуту с одного IP).
- Если таблица недоступна, клиент видит «Трекинг временно недоступен, позвоните менеджеру».
